The pipeline — 9 phases, your call at every gate

01

Research

Find the angle worth building, not the obvious clone.

02

Concept

The hook, the core loop, and a visual first look — you approve it.

03

Design

A real game-design doc scoped to what you actually want.

04

Code

A fully-playable build first — mechanic before polish.

05

Art

Consistent, generated sprites, UI and backgrounds — real, not gray-box.

06

Sound

SFX and music wired into the moments that matter.

07

Levels

A difficulty curve tuned for retention, not random.

08

Polish

Juice, menus, transitions — the feel that makes it land.

09

Deploy

Built and shipped — a real URL you can play and share.

You stay in control. ongame pauses at every gate to show you what it made and get your yes before moving on — and it verifies the game really runs in a browser before ever calling it playable.

How it works

1

Install once

The one-liner above installs ongame and registers the Claude Code plugin automatically — nothing to paste. Already in a session? Run /reload-plugins.

2

Sign in once

The first cloud feature opens a quick browser sign-in — the assistant walks you through it. After that it's seamless.

3

Make games

Say /make-game <your idea> and go. Check your plan and usage anytime with /account.

Not just another AI wrapper

🎨

Real assets, one art direction

Generated sprites, characters, UI and sound in a single consistent style — wired into the game, not dumped in a folder.

🎚️

Tuned to keep players

Level curves and game-feel built on what actually retains, so the result plays like a game — not a demo.

✅

Verified, then shipped

Every build is checked in a real browser and deployed to a live URL. "Playable" means it actually plays.
