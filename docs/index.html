Install ongame with one command.

ongame-cli is the CLI and Claude Code / Codex plugin transport for ongame, an AI game-making assistant. One line installs a checksum-verified binary, wires up your agentic tool, and keeps itself current on every launch — no reinstalls, no manual updates.

terminal
$ curl -fsSL https://raw.githubusercontent.com/gamebyte-ai/ongame-cli/main/install.sh | sh
macOS (arm64 / x64) Linux (x64 / arm64) Windows — coming soon

What the installer does

1

Detects your platform, fetches the right binary

OS/arch detection (including Rosetta on Apple Silicon), downloads the matching release asset, verifies its sha256 against a published checksum, and installs it to ~/.ongame/bin.

2

Wires up your agentic tool — automatically

Detects Claude Code and registers the plugin for you (marketplace + install, no commands to paste). Detects a Codex CLI install and patches its MCP config the same way. Already in an open Claude Code session? Just run /reload-plugins.

3

Start building

Open a Claude Code (or Codex) session and type your idea:

/make-game a cozy match-3 with a weather twist

The first cloud feature opens a one-time browser sign-in — the agent walks you through it, then takes your concept through research, design, code, real generated art & sound, levels, and polish, with your approval at every gate.

How updates work

> No manual step, ever

The plugin manifest is a tiny, near-permanent shim. All real version churn lives in the ongame-cli binary itself, which checks for a newer release on every launch.

> Verified before it runs

Every self-update downloads a fresh checksum file and refuses to install anything that doesn't match — a broken download just falls back to the version you already have.

> Never blocks your session

Update checks are time-bounded. Offline, rate-limited, or on a slow network, the existing binary launches immediately — self-update is best-effort, not a gate.

> Takes effect next session

Same as any other Claude Code/Codex config change — a new version is picked up the next time you start a session, not mid-session.
